## 機房位置怎麼選？亞洲用戶直接看美國西岸

台灣、香港和中國大陸用戶首選洛杉磯 DC-02，搶不到就 DC-03 或聖荷西；目標用戶在東南亞選新加坡；除非業務在歐洲，否則別碰東岸機房。

**洛杉磯 DC-02** 是招牌機房，位於 Multacom 機房，對亞洲方向做了路由優化，聯通去程走直連，延遲低的時候 150ms 左右，跑網頁、掛服務都夠穩。缺點是太熱門，節假日前後幾乎一直缺貨，看到有貨就直接下手，不要猶豫。

**洛杉磯 DC-03** 在市中心另一棟設施，接入 Cogent、Arelion 等主流運營商，有 SOC2 和 PCI DSS 認證。延遲表現比 DC-02 略遜一點，但比東岸強得多，是缺貨時的合理替代。

**聖荷西** 在加州灣區，電信和聯通的表現都還可以，平均延遲大約 160–180ms。因為選的人相對少，資源充裕，比較不容易碰到超售。**西雅圖**排第三備選；**新加坡**是 RackNerd 在亞太唯一的本地機房，東南亞用戶延遲優勢明顯，只是套餐選擇少一些。面向歐洲業務才考慮阿姆斯特丹、斯特拉斯堡或法蘭克福。紐約、新澤西、阿什本、亞特蘭大這幾個東岸節點，台港連過去延遲普遍 230ms 以上，除非跑的服務完全不在乎延遲，否則不建議。

## RackNerd 購買流程實操：五步完成結帳

1. **進入套餐頁**：從上面的表格點「立即購買」，進入對應方案的購物車頁面。
2. **選機房和作業系統**：Location 按前面的建議選西岸城市；作業系統新手選 Ubuntu 22.04，社群資料多、出問題好查，習慣 CentOS 的可以選 AlmaLinux；付款週期直接選年付。頁面上還可以加購額外 IP，不需要就保持預設——方案本身已含 1 個獨立 IPv4。選完點 Continue。
3. **填寫帳號資訊**：第一次購買會同時註冊帳號，信箱必須能正常收信，因為開通郵件會寄到這裡。姓名地址建議填真實資訊，降低被風控判為異常帳戶的機率。
4. **付款**：勾選同意服務條款，點 Complete Order，再選支付方式。支付寶會跳出 QR Code 掃碼即付，PayPal 和信用卡照正常流程走。
5. **等開通郵件**：付款成功後幾分鐘到十幾分鐘內，信箱會收到開通郵件，裡面有 IP 位址、SSH 埠和 root 密碼——這三樣是下一步連線要用的。

## 收到郵件後：連上伺服器並完成初始化

郵件裡最關鍵的三個資訊是 IP 位址、SSH 埠（預設 22，偶爾會是其他埠，一切以郵件為準）和 root 密碼。

Windows 用 Xshell 或 MobaXterm：新建連線，填入 IP 和埠，使用者名稱填 root，密碼照郵件輸入即可。Mac 和 Linux 直接開終端機：


ssh root@你的IP位址 -p 埠號


連上之後建議先做三件事。改掉預設 root 密碼（執行 `passwd`，輸入兩次新密碼）；更新系統（Ubuntu／Debian 用 `apt update && apt upgrade -y`，CentOS／AlmaLinux 用 `yum update -y`）；在意傳輸速度的話把 BBR 開起來，RackNerd 的內核大多需要手動開啟：


echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf
sysctl -p


打算建站的話，再裝一個寶塔面板這類視覺化管理工具，之後用網頁介面管理網站、資料庫和 PHP 環境，不用全程敲命令。

## SolusVM 控制台：日常管理在這裡

RackNerd 的 VPS 配 SolusVM 管理面板，地址是 `nerdvm.racknerd.com`，帳號密碼在開通郵件裡。日常會用到的功能：伺服器卡死時重啟或強制重啟；一鍵重裝系統（重裝後會產生新的 root 密碼，記得複製保存）；查看當月流量使用量；忘記 root 密碼時在面板直接重置；VNC 控制台則是 SSH 連不上時的備用入口。

最重要的一件單獨說：

> **RackNerd 不支援退款。** 這條明確寫在官方服務條款裡。所以別把它當免費試用平台——先 Ping 測試 IP 確認延遲，再從最便宜的年付方案開始，跑幾個月確認穩定了，再考慮續費或升配。

- **洛杉磯 DC-02 經常缺貨**，尤其節假日前後，看到有貨別糾結太久。

- **配置只能升不能降**，升級過程需要重啟，大約 1 分鐘停機。多機房套餐可以發工單申請免費遷移機房，但遷移後 IP 會變、資料會清空，務必先備份。

## RackNerd 購買常見問題

**支援哪些付款方式？**
支付寶、PayPal、信用卡和比特幣都支援。華人用戶用支付寶最直接，掃碼即付；台灣用戶用信用卡或 PayPal 也沒問題。

**SSH 顯示 Connection refused 怎麼辦？**
先核對 IP 和埠是否抄對，以開通郵件為準；剛開通的機器可能還在初始化，等幾分鐘再試。還是不行就登入 SolusVM 面板確認伺服器是否處於運行狀態，必要時用 VNC 控制台檢查。

**忘記 root 密碼了怎麼辦？**
登入 SolusVM 面板直接重置，不用發工單。

**可以換機房或升級配置嗎？**
多機房可選的套餐可以透過工單申請免費遷移，但 IP 會變、資料會丟，遷移前先備份；低價年付方案的遷移可能有限制，以工單回覆為準。升級隨時可以做，只升不降，過程約 1 分鐘停機。

**特惠年付方案的機房可以隨便選嗎？**
特惠方案標註 Multiple Locations，一般包含洛杉磯、聖荷西、西雅圖、達拉斯、芝加哥、亞特蘭大、阿什本等城市，下單時系統會讓你選。亞洲用戶建議優先洛杉磯或聖荷西。
